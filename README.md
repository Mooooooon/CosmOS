# CosmOS — 虚拟手机系统

> 一款运行在 Android 上的沉浸式虚拟手机体验，让你与 AI 角色共享同一个虚拟世界。

---

## 📖 项目简介

**CosmOS** 是一个以"虚拟手机"为核心交互界面的 Android 应用。  
你扮演一名身处虚拟世界的用户，手机桌面上安装着各类应用，通过它们与虚拟 AI 角色建立真实而立体的关系——聊天、线下互动、写日记、刷推文，甚至可以让时间流逝，让角色在你不在时继续生活。

一切都发生在你的手机屏幕里。

---

## ✨ 功能概览

### 🖥️ 虚拟手机桌面

- 仿真手机主界面，支持 App 图标排布
- 顶部状态栏：显示信号、电量、网络等虚拟状态
- 时钟栏：显示虚拟世界的当前时间

---

### 📱 应用列表（规划中）

#### ⚙️ 设置

- 配置 AI 服务商（API Key、模型选择、Endpoint 等）
- 档案管理：新建、切换、删除存档

#### 🗂️ 档案

- 设置**用户**的线下真实信息（姓名、外貌、性格、背景等）
- 设置**角色**的线下真实信息（真实姓名、照片、人设提示词等）
- 角色信息作为 AI 推理的基础上下文

#### 💬 聊天

- 角色与用户各有独立的**线上**头像、昵称、个性签名
- 类似 QQ 的即时消息界面，支持多角色独立会话
- AI 驱动的对话生成，带有角色人格记忆

#### 🎭 互动

- 用户与角色进行**线下场景互动**，类似语C（语音/文字角色扮演）
- 自由描述场景，AI 以角色身份实时响应

#### 📔 日记

- 通过日记推进**线下故事**
- 类似 AI 角色扮演或文字小说形式
- 记录并回顾与角色的故事进程

#### 🐦 推特

- 角色与用户各有独立的**线上**推特头像、昵称、简介
- 发布推文、转发、评论，角色也会主动发帖
- 构建虚拟社交网络的日常氛围

#### ⏰ 时间

- 手动跳过虚拟世界的时间
- 时间流逝期间，AI 自动推演角色的日常生活
- 角色可能**主动**向用户发送聊天消息或发布推文
- 让世界在你"离线"时依然运转

## 🚀 快速开始

### 环境要求

- Android Studio Meerkat 或更新版本
- JDK 11+
- Android 12+ 设备或模拟器

### 构建步骤

```bash
git clone https://github.com/your-username/CosmOS.git
cd CosmOS
```

在 Android Studio 中打开项目，同步 Gradle 后运行即可。

### 配置 AI 服务商

首次启动后，进入 **设置 → AI 服务商**，填写你的 API Key 和模型信息。目前支持任意 OpenAI 兼容接口。
